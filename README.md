# 吃什么

给家里排未来七天的菜。每天可以有早餐、午餐和晚餐，每道菜记下名字、做法，以及要用的食材。食材有名字和份量，单位是克、毫升或个。还没备好的不打勾，采购页把这七天里没打勾的按名字加在一起。

家里已经有的食材单独记在「家里」。把其中一笔放进某道菜时，家里的份量减少，菜下面已备好的份量增加；如果这道菜里还有同名同单位、没打勾的一行，那一行会减去同样的份量，避免已经从家里拿出来的东西还留在采购单上。放回去则只把已备好的份量退回家里，不会自动把采购单加回来。

写一道新菜时，如果服务器配了和记账相同的 DeepSeek 密钥，可以按菜名生成一份两人份的家常食材和简短做法。生成只是填进表单，改完点保存才写入。密钥留在服务器上，不会发到浏览器。

界面按手机浏览器设计，也可以加到主屏幕。页面不加载外部资源。

## 本地运行

需要 Go 1.27 以上。

```
make run          # 账号 dev / devdevdev，监听 127.0.0.1:18082
make test         # go vet + go test
make build-linux  # 交叉编译出 dist/chishenme-linux-amd64
```

第一次启动、数据库里还没有账号时，用环境变量里的用户名和密码建账号。之后这两项会被忽略。

## 配置

服务器上的变量放在 `/etc/chishenme/env`，由 `deploy/server/setup.sh` 在文件还不存在时生成。

| 变量 | 默认值 | 说明 |
| --- | --- | --- |
| `CHISHENME_ADDR` | `:18082` | 监听地址 |
| `CHISHENME_DB` | `chishenme.db` | SQLite 文件 |
| `CHISHENME_ADMIN_USER` | `admin` | 只在还没有账号时使用 |
| `CHISHENME_ADMIN_PASSWORD` | 无 | 初始密码，至少 8 位；没有账号又没设密码时程序会退出 |
| `CHISHENME_SECRET` | 无 | 会话签名密钥，至少 16 个字符。留空则每次启动随机生成，已登录的会话会失效 |
| `CHISHENME_TLS_CERT` | 无 | 证书。和私钥要么一起填，要么都不填 |
| `CHISHENME_TLS_KEY` | 无 | 私钥 |
| `CHISHENME_DEEPSEEK_KEY` | 无 | 留空则没有「按菜名生成食材」 |
| `CHISHENME_DEEPSEEK_URL` | `https://api.deepseek.com` | 一般不用改 |

## 部署

这台个人服务器上，记账监听 18080，吃什么监听 18082。两个程序都自己提供 HTTPS，前面没有 nginx。防火墙只放行 22、18080 和 18082。

在本机执行 `deploy/deploy.sh`。它会编译、在服务器上准备账号目录和证书（已有的配置和数据库不会覆盖），打开 18082，然后重启服务。第一次生成环境文件时，初始密码打在这条命令的输出里，只出现一次。用户名和记账管理员相同。登录后可以在设置里改密码，改完需要重新登录。

浏览器第一次打开 `https://服务器地址:18082` 会警告自签名证书，接受一次即可。也可以把页面加到手机主屏幕。
